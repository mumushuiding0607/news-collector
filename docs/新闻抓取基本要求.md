# 新闻抓取基本要求 - 检查清单


## list_cleaned 阶段

- [ ] 1. 保留新闻列表的最小容器（必须包含整个列表结构，同时用于确定位置的class或id必须是唯一值,优先找id，防止定位错误，找错列表,ssm数据源包含两个新闻列表dom块：唯一定位标识符wrapper-left-content mr35和wrapper-right-content）
- [ ] 2. 保留日期、时间元素
- [ ] 3. 清除中文字符数 < 10 且非日期/时间格式的 DOM 元素（贪婪模式，连同后代一起移除）
- [ ] 4. 无用属性用空字符替代
- [ ] 5. 清除 HTML 注释、空格、script、style 等无用内容
- [ ] 6. 最终必须保留新闻列表（至少 1 条新闻链接）
- [ ] 7. http://tv.cctv.com/lm/hqcjlx/index.shtml 和 http://news.smm.cn/live 都是有日期的，检查一下是否有被清洗掉
- [] 8.  同一个数据源，每个新闻列表dom块它的最顶级的dom元素的id或class应该是唯一的
9. 禁止把新闻列表中的新闻的标题、摘要、日期和时间及相应的dom定位标识洗掉要完整保留

## list_truncated

1. 新闻列表dom块结构要完整
2. 新闻列表dom块新闻只需要3个
3. 日期如果在list_cleaned时存在，list_truncated之后也要存在
3. 每条新闻的标题、摘要、发布日期时间，如果在list_cleaned时存在，list_truncated之后也要存在

## article_cleaned
1. 清除中文字符数 < 50 且非日期、时间格式的 DOM 元素（贪婪模式，连同后代一起移除）
2. 定位正文位置的选择器必须是唯一的


## 二、通用性

- [ ] 7. 禁止针对特定网站写算法，必须通用

## 三、正文清洗

- [ ] 8. 正文内容尽可能排除无用内容
