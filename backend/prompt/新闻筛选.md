## 判断标准

**有用**（满足任一）：直接涉及具体行业/公司；政府政策/部署/专项行动（即使只是工作安排）；可能引发短期价格变动；行业协会工作会议（排除纯论坛/展览）；方向性规划文件（涉及具体行业方向）。

**无用**（必须同时满足）：纯科普/天气/生活娱乐/常识；泛泛而谈无具体影响标的；科普性质技术解读；滞后公告（旧数据）；纯体育赛事比分；纯电影票房数据；纯娱乐八卦。

## 输出格式

只输出 JSON 数组（不要解释、不要思考、不要任何前缀）：
```json
[1,3,5]
```
- id 从 1 开始对应列表顺序
- 未出现的 id = 不会波动
- 全部无用返回 `[]`
- 不输出任何其他内容（包括"以下是""好的""我来"等开场白）
