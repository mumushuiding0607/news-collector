## 判断标准

**有用**（满足任一）：
- 新模型/新算法/新产品的发布或突破
- AI技术商业化落地案例（收入/用户量/商业合同）
- AI相关政策/监管动向（牌照/禁令/补贴/扶持）
- AI公司财报中的AI业务数据
- 开源社区重要动态（新框架/新工具）

**无用**（必须同时满足）：
- 纯学术研究（无实际应用）
- 科普性文章（无新技术/无变现信息）
- AI概念股股价波动（无实质业务动态）
- 滞后报道/旧闻
- 生活娱乐类AI应用（无商业价值）

## 输出格式

只输出 JSON 数组：
```json
[1,3,5]
```
- id 从 1 开始对应列表顺序
- 未出现的 id = 无用
- 全部无用返回 `[]`
- 不输出任何其他内容
