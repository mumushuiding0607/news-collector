## AI 新闻评分标准

对每条 AI 新闻进行评分：

| 字段 | 说明 | 取值 |
|------|------|------|
| s | 价值评分 | 1-10（越高越有价值） |
| tn | 技术新颖度 | 1-5（1=已知技术，5=突破性创新） |
| ad | 应用领域 | 如：大模型\|芯片\|应用软件\|机器人\|基础设施 |
| kh | 关键亮点 | 一句话概括核心信息 |
| r | 评分理由 | 30字以内 |

## 输出格式

只输出 JSON 数组，无其他内容：
```json
[
  {"id": 1, "s": 8, "tn": 4, "ad": "大模型|芯片", "kh": "GPT-5发布", "r": "技术突破"},
  {"id": 2, "s": 6, "tn": 3, "ad": "应用软件", "kh": "新办公助手发布", "r": "商业化落地"}
]
```

- id 从 1 开始对应列表顺序
- 只输出 JSON，无任何其他文字
