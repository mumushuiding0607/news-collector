# 新闻列表发现

## 任务
分析新闻网站 URL，返回存入 source_crawl_configs 的配置。

## 输入
- url: 新闻网站 URL
- html: 网页 HTML（已清洗，**文本内容已替换为占位符如"标题样例"/"日期样例"/"摘要样例"**，仅 DOM 结构 + class/id/href/src 保留）

## 分析流程
1. **检测页面结构**：分析 HTML 中的新闻列表容器和条目
2. **多列表块识别**：若存在多个新闻列表 DOM 块，按下方「多列表块识别规则」选出**唯一目标块**
3. **提取 CSS 选择器**：提取列表容器、条目、标题、链接、日期和时间的选择器
4. **URL模式分析**：从新闻链接提取日期规律和URL结构

## article（样本文章）选取规则

`article` 字段必须是**具体的单篇新闻**，不能是节目整期/合集页、栏目主页/专题页、导航/广告/外链。

**判别优先级**（命中即停）：
1. 用户提供了已知标题 → 选标题完全匹配的那条
2. **长度最像新闻**：优先选标题长度 ≥ 10 字的链接（节目整期通常 ≤ 8 字）
3. **同源最新**：在剩余候选中选日期最新的那条
4. **DOM 兜底**：选列表中第一个新闻项的链接

**负向过滤**（任何路径都先排除）：
- 标题 ≤ 6 字且日期缺失（很可能是节目名或栏目名）
- URL 路径不含日期（栏目根 `/lm/xxx`、专题页 `/topic/xxx`）
- 标题含"全集/整期/合集/回顾"等关键词

## 多列表块识别规则

### 路径 A：用户提供了已知标题
- 选**新闻标题与已知标题匹配**的 DOM 块
- 匹配：完全相等 / 去空白后相等 / 去标点后相等
- 命中即停

### 路径 B：用户未提供标题（按优先级）
1. **完整度最高**：块内新闻同时具备 标题 + 摘要 + 当天日期 + 时间
2. **全当天**：块内所有可见新闻日期都是当天
3. **首块兜底**：选 HTML 中第一个新闻列表 DOM 块

### 通用负向过滤（任何路径都先排除）
- **导航/翻页**：含"首页""上一页""下一页""末页""更多"
- **侧栏/聚合**：class/id 含 `sidebar` `hot` `recommend` `related` `rank` `top`（全站仅一块时例外）
- **广告/推广**：链接指向落地页（`/goto?` `/ad?` `click.aliyun.com` 等）
- **外部链接聚合**：块内 URL 跨多个不同域名
- **数量过少**：有效新闻项 < 3 条（全站都少时例外）
- **时间断裂**：混入远古日期（如 2024 年），多为聚合页/历史回顾

## 输出（JSON）

```json
{
  "name": "数据源名称",
  "source_type": "html",
  "publish_time_pattern": "时间提取正则（可选）",
  "article": {
    "url": "样本文章URL",
    "title": "样本文章标题",
    "publish_time": "发布时间（格式 2026-06-13 09:19:59）"
  },
  "list_config": {
    "type": "html",
    "selector": {
      "container": "列表容器（ul/ol/div/section/table）",
      "item": "列表项（li/tr/div/article）",
      "title": "标题元素（a/h1-h5/span）",
      "url": "链接选择器（支持 @属性 后缀，如 a@href）",
      "date": "日期/时间元素（span/time/em/div/p，或 time@datetime）",
      "summary": "摘要/导语元素（可空）"
    },
    "css_selector": "完整 CSS 选择器（可选）",
    "url_pattern": "URL正则（可选）"
  }
}
```

## 规则
- 只识别 HTML 直接渲染的页面结构
- 不检测 API / AJAX
- 选择器要精确，能唯一匹配到目标元素
- 字段不存在时返回空字符串

## 严格输出格式（必读）

**只输出一个 ```json 代码块**，**不要输出任何解释、Markdown 标题、自然语言说明或 HTML 代码块**。

- 必须是合法 JSON，可被 `json.loads` 直接解析
- 不允许把 JSON 嵌在分析文字里
- 不允许用 ```html / ```xml 等其他围栏
- 不允许省略字段（字段不存在就用空字符串 ""）

正确示例（单行紧凑 JSON，便于解析）：
```json
{"name":"xxx","source_type":"html","publish_time_pattern":"","article":{"url":"...","title":"...","publish_time":""},"list_config":{"type":"html","selector":{"container":"...","item":"...","title":"...","url":"...","date":"","summary":""},"css_selector":"","url_pattern":""}}
```

错误示例（绝对禁止）：`## 结论` 等 markdown 标题、带文字段落、```html 围栏、前后缀注释。
