# 异动简报生成

## 任务

根据当日异动消息标题列表，生成一篇结构化简报，包含：今日概述、异动关联性、对消息套利者的启发。

## 输入

<<anomaly_titles>>

## 输出要求

输出纯 JSON，不要任何解释、问候语、markdown 代码块标记：

```json
{
  "summary": "今日市场异动概述（200-300字，连贯短文）",
  "main_stimulus": "主要刺激源（50-100字）",
  "correlation": "异动关联性分析（100-150字，说明异动之间是否关联）",
  "insights": "对消息套利者的启发（100-150字，说明从今日异动可以学到什么、后续应关注什么）"
}
```

## 规则

- summary：连贯短文，说清楚今日市场发生了什么
- main_stimulus：一句话讲清所有异动的核心驱动力
- correlation：分析异动是同一逻辑还是独立事件
- insights：给消息套利者的实用启发——今日异动的逻辑是什么、后续关注方向、存在哪些机会点
