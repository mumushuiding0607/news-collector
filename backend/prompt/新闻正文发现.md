# 新闻正文发现

## 任务
从文章页 HTML 中定位正文容器与发布时间元素。

## 输入
- url: 文章页 URL
- html: 清洗后的 HTML（文本已替换为占位符，仅 DOM 结构 + class/id/href/src 保留）
- headline: 已知文章标题（用于正文消歧）

## 输出（JSON）

```json
{
  "content_extract": {
    "selector": "正文容器 CSS 选择器",
    "time_selector": "发布时间 CSS 选择器（可空）"
  },
  "publish_time_pattern": "时间提取正则（可空）"
}
```

## 核心逻辑

**正文判断标准**（非枚举，基于结构特征）：
1. 正文文本节点长度 >30 字
2. 正文分布在**多个** DOM 元素中
3. 这些元素被**同一个父容器**包住 → 父容器即为正文容器
4. 时间/阅读数等元信息文本长度 ≤30

## 分析流程

### 1. 页面类型识别
按 URL 与结构判断：文章页（正文段落父容器）/视频页（视频简介容器）/直播页（快讯正文容器）/专题页（主文章区，不要选整页）。

### 2. 正文定位（三步法）

**Step A — 筛选正文候选元素**：遍历所有文本节点（排除 script/style 等），文本长度 >30 字的视为正文节点候选。

**Step B — 找最小公共父容器**：对所有正文候选节点向上追溯，找它们的**最小共同祖先**。

**Step C — 验证与调整**：
- 父容器内部若混有时间元素、侧边栏、导航等——这些**不改变父容器选择**
- 若父容器过大（如包含整个侧边栏），选择其内部**直接包含正文段落**的子容器
- 多个候选都满足条件时，选**最小**那个

### 3. 时间提取
- 优先 class（`.time`、`.date`、`.publish-time`、`.pub-date` 等）
- 选**文章发布时间**，避开只含浏览量/点击的元素
- 若日期和时间拆成多个同级元素，time_selector 必须选**包含这些子元素的父容器**或**所有子元素共有的 class**，不能只选其中一个

## selector 规则

**必须**：输出单一有效 CSS 选择器。
**禁止**：逗号分隔多个 selector；列表类 selector（`.index`、`.list`）；太大容器（`body`、`html`）；只含元信息的容器。

## publish_time_pattern

覆盖常见格式（可空，未匹配时回退到 time_selector）：
- `\\d{4}-\\d{2}-\\d{2}\\s+\\d{2}:\\d{2}:\\d{2}` （如 `2026-06-09 10:30:00`）
- `\\d{4}年\\d{1,2}月\\d{1,2}日\\d{1,2}:\\d{2}` （如 `2026年06月09日10:14`）
- `\\d{4}-\\d{2}-\\d{2}` （如 `2026-06-09`）
