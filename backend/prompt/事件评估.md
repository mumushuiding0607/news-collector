# 事件评估与板块识别

## 评估原则
根据实际内容评估，内容短不跳过。

**输入可能为**：完整正文 / `[摘要] xxx` / `[标题] xxx`，可任意组合。
**评分优先级**：完整正文 > 摘要 > 标题（标题本身就是新闻事件）。

**wf=false**（跳过）：纯科普、天气预报、生活娱乐、已消化事件评论。
**wf=true**（评分）：标题或摘要已说明事件，含具体数字/措施/时间节点。

## 前置判断
- **新建事件**：首次宣布/发布/披露，市场未定价 → 正常评分。
- **二手评论**：引用旧事件（>1个月）表态/分析 → 降档（intst≤3, dur≤中期, 必要时 wf=false）。
  - 线索：时间标志词（几个月前、半年前、此前、已经）。

## 评分维度
- 方向（dir）：积极 / 消极
- 强度（intst）：1-5（5=改变行业格局）
- 波幅（chg）：±%（±2%=1, ±5%=2, ±10%=3, ±20%=4, >±20%=5）
- 持续（dur）：超短期/短期/中期/长期/永久

`score = intst×0.7 + 波幅×0.15 + 持续×0.15`

## 四维定性
- 本质属性：宏大叙事 / 消息
- 参与者结构：全市场资金 / 单一资金
- 清晰度：模糊长逻辑 / 清晰短期可兑现
- 基本面深度：改变估值模型/增长曲线 / 仅影响增长曲线斜率

输出 `lvl`（重大/中等/较小预期）+ `md`（趋势主升/脉冲式/其他）。

## 板块识别
输出 1-2 个最受益板块，**必须匹配同花顺标准板块名**，用 `|` 分隔。

## 待评估新闻
每条以 `--- NEWS <序号> ---` 分隔，**独立评估每条**，按相同顺序返回 JSON 数组。

<<news_list>>

## 输出格式

```json
[
  {
    "seq": 1, "wf": true,
    "sum": "50-100字概括",
    "sec": "板块1|板块2",
    "score": 7, "reason": "30-80字依据",
    "dir": "积极", "intst": 4, "chg": "±5%",
    "dur": "短期", "lvl": "中等预期", "md": "脉冲式"
  },
  {"seq": 2, "wf": false}
]
```

**约束**：
- `seq` 必填，从 1 开始
- `wf=false` 只返回 `{seq, wf}`，其他字段可省
- `wf=true` 必须给完整 11 字段
- 只输出 JSON，无其他文字/注释/markdown
- 内容相似也要独立判断，不要抄前一条

## 评估示例
**仅有标题的快讯**（帮助把握 wf 判定）：
- "中东冲突影响树脂供应 电子产品制造商成本增加" → wf=true
- "国务院宣布对美加征关税" → wf=true
- "公司发布日常公告" → wf=false
