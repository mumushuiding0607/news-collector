# 核心标的筛选提示词

<<news_content>>

---
**重要：以上可能包含多条新闻，请逐一分析，每条新闻输出独立的核心标的 JSON 数组。最终输出一个包含所有新闻标的的大数组，每条记录额外标注 `news_index` 表示属于第几条新闻（从0开始）。**

---

## 第一步：识别受益方

- 生产/供应该产品的A股公司 → 直接受益
- 使用该产品作为原材料的公司 → 成本受益/受损
- 竞争对手/替代技术相关公司 → 间接受益/受损
- 关联上下游的公司 → 联动受益

## 第二步：全产业链拆解

对新闻事件涉及的核心产品，从原材料到终端消费拆解产业链全貌，每一环节标注"☑ 已覆盖"或"本事件无此环节"，并标注：价值量占比(%)、技术壁垒(高/中/低)、供需格局(紧缺/平衡/过剩)、是否卡脖子(是/否)

## 第三步：四维度评估

对受益标的逐一评估：
1. 竞争格局与市场地位：全球/国内市占率排名，是否独家/寡头，是否具备定价权
2. 盈利质量与商业模式：毛利率/净利率水平与趋势，是否具备定价权/成本转嫁能力
3. 客户与供应链壁垒：是否深度绑定头部客户（必须列出客户名称），切换成本是否极高，是否已规模供货（严格区分"送样"与"量产"，仅送样必须降级）
4. 技术/品牌/模式壁垒：是否在下一代技术路线占据先发，或品牌/渠道具备显著护城河

**纳入标准**：
- 条件A：至少两个维度为"高"，且无维度为"低"
- 条件B：某一维度为"极高"（如国内唯一供应商、全球市占率>60%），其他维度为"中"也可纳入
- 条件C：进入多个核心客户供应链的稀缺标的，且至少一个维度为"高"

## 第四步：剔除规则

必须剔除：
1. 非A股（港股、美股、SPAC、借壳上市）
2. 仅多层间接参股且无实际业务往来；弱关联服务
3. 主业或核心利润来源与新闻事件关联收入占比<60%
4. 仅有"送样"、"试验"、"在谈"而无量产/批量供货/明确订单
5. 最近两季度持续亏损且无明确扭亏指引；年净利<2000万元
6. 模组/组件/流通环节标的须满足：①具备核心环节自控能力；②具备显著渠道或客户壁垒；③最近季度净利率>行业平均且营收增速>20%

## 第五步：交叉验证

与同花顺该板块成分股列表、近3个月券商研报覆盖标的、近1个月涨幅前20标的交叉比对，确保无遗漏。

## 第六步：分层定级

| 层级 | 定义 |
|:---|:---|
| 第一梯队 | 全球市占率前3 + 至少三个维度为"高" |
| 第二梯队 | 国内市占率第一 + 至少两个维度为"高" |

**只输出第一、第二梯队**，第三梯队不输出。

## 输出格式

输出标准JSON数组，每只标的为一个对象：

```json
[
  {
    "code": "000001",
    "name": "平安银行",
    "tier": "第一梯队",
    "chain_link": "中游制造",
    "four_dims": {"竞争": "高", "盈利": "高", "客户": "中", "技术": "高"},
    "moat": "全牌照银行，零售转型领先",
    "news_related": "受益于AI驱动的金融科技需求增长"
  }
]
```
