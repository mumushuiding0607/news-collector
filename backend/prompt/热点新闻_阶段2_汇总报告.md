# 热点新闻阶段2：汇总报告

## 任务

根据各条新闻的结构化摘要，生成一份完整的热点新闻报告。

## 输入

<<summary_items>>

## 输出要求

输出标准JSON对象：

```json
{
  "summary": "今日热点新闻概述（200-300字，连贯短文）",
  "main_stimulus": "今日核心驱动（50-100字）",
  "sector_analysis": "板块强度分析（100-150字，各板块的强度和持续性）",
  "market_outlook": "市场展望（100字左右，明日关注方向）",
  "insights": "对消息套利者的启发（100-150字）"
}
```

## 规则

- summary：连贯短文，说清楚今日市场发生了什么，关注哪些主线
- main_stimulus：一句话讲清今日最核心的驱动力
- sector_analysis：分析各板块的强度、轮动关系、持续性判断
- market_outlook：基于今日信息，对明日市场走向的判断
- insights：给套利者的实用建议——关注哪些方向、规避哪些风险
- 只输出JSON，不要任何解释、markdown标记
