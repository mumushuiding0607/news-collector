# 热点新闻阶段1：分篇摘要

## 任务

对每条高分新闻提取关键信息，生成结构化摘要。

## 输入

<<news_items>>

## 输出要求

输出标准JSON数组，每条新闻为一个对象：

```json
[
  {
    "title": "原始标题",
    "brief_summary": "50-100字简要概括这条新闻的核心内容",
    "stimulus": "一句话说明刺激源（什么事件/政策/数据驱动）",
    "sectors": ["相关板块1", "相关板块2"],
    "significance": "高/中/低（对市场的影响程度）",
    "expected_change": "涨/跌/震荡/扩散（预期市场反应方向）",
    "reason": "该新闻为何重要（入围原因）"
  }
]
```

## 规则

- brief_summary：基于 provided_summary 提炼核心内容，保持50-100字
- stimulus：识别核心驱动因素（政策/数据/事件/业绩等）
- sectors：来自 related_sectors 字段，基于内容推断补充
- significance：高=主线龙头/政策核心受益，中=板块联动，低=边缘影响
- expected_change：基于 intensity 和 expected_change 字段判断
- reason：来自字段，保持简洁
- 只输出JSON，不要任何解释、markdown标记
