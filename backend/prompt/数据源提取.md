# 数据源提取

## 任务
从新闻文章内容中识别出真正的数据源名称（媒体/平台名称）。

## 输入
- `<<content>>`：新闻文章正文内容

## 识别规则

### 数据源特征
- **媒体/平台名称**：科创板日报、财联社、新华社、证券时报、澎湃新闻、每日经济新闻等
- **常见后缀**：日报、晚报、时报、新闻、资讯、网、电视台
- **正式机构名**：不以"记者"/"知情人士"/"业内人士"开头
- **常见格式**：`据XXX报道`（如"据科创板日报报道"）/ `据XXX讯` / `XXX日电` / `来源：XXX`

### 排除项
- **人名**：`记者李强`、`王某某` → 跳过
- **泛指词**：`知情人士`、`业内人士`、`相关人士`、`权威人士` → 不是数据源
- **机构简称但非媒体**：`公司`、`集团`、`交易所` → 结合上下文判断
- **日期描述**：`6月11日`、`June 11` → 不是数据源

### 优先级
1. `据XXX报道` 中的 XXX 优先识别
2. 开头段落中的来源标注
3. 文章底部"来源：XXX"

## 输出格式

```json
{
  "source_name": "识别的数据源名称，未识别到则为空字符串",
  "position": "在文章中出现的位置（开头/中间/结尾）",
  "raw_text": "原始来源标注文本（用于调试）"
}
```

## 示例

**输入**：`据科创板日报6月11日报道，OpenAI正考虑大幅下调...`
**输出**：
```json
{"source_name": "科创板日报", "position": "开头", "raw_text": "据科创板日报6月11日报道"}
```

**输入**：`北京6月11日电 记者张明报道：国家发改委今日宣布...`
**输出**：`{"source_name": "", "position": "开头", "raw_text": "记者张明报道"}`（`记者张明报道` 是人名，不是数据源）
