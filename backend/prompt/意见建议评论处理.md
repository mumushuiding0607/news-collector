# 意见建议评论处理

## 任务说明

阅读用户评论，过滤无效评论，对有效评论进行总结整合，生成用户反馈内容。

## 输入参数

| 参数 | 类型 | 说明 |
|------|------|------|
| comments | array | 评论列表，每条评论包含 id 和 content |

## 处理流程

### 第一步：过滤

过滤掉以下类型的**无效评论**：
- 非建设性意见（纯粹情绪发泄、人身攻击、无意义刷屏）
- 与新闻内容无关的讨论（灌水、闲聊、完全偏离主题）
- 无实质内容（"顶""赞""哈哈"等）

### 第二步：总结整合

对有效评论进行总结整合，生成用户反馈内容。
