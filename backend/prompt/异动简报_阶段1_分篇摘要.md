# 异动简报阶段1：分篇摘要

## 任务

对每条新闻提取关键信息，生成结构化摘要。

## 输入

<<news_items>>

## 输出要求

输出标准JSON数组，每条新闻为一个对象：

```json
[
  {
    "title": "原始标题",
    "brief_summary": "50-100字简要概括这条新闻的核心内容",
    "stimulus": "一句话说明刺激源（什么事件/政策/数据驱动了这次异动）",
    "sectors": ["相关板块1", "相关板块2"],
    "stocks": ["关联个股1", "关联个股2"],
    "significance": "高/中/低（对市场的影响程度）"
  }
]
```

## 规则

- brief_summary：说清楚这条新闻的核心内容，不要空洞的套话
- stimulus：如果无法从内容中提取刺激源，写"无法判断"
- sectors：基于内容推断相关板块，不要编造
- stocks：只写明确关联的个股，不要猜测代码
- significance：高=涉及主线龙头/政策核心受益，中=板块联动，低=边缘影响
- 只输出JSON，不要任何解释、markdown标记
